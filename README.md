# Бот проверки наличия товара

Пользователь пишет название товара, бот ищет его на сайтах из `sites.json` и отвечает
«✅ В наличии» (если товар есть хотя бы на одном сайте) или «❌ Нет в наличии».
Название может совпадать не полностью: «ставр 9 термофор» найдёт «Печь отопительная ТЕРМОФОР Ставр 9…».

Администратор:
- получает уведомление при каждом положительном ответе: запрос, пользователь, сайт и ссылка на товар;
- `/log` — последние запросы, `/export` — все запросы в CSV (открывается в Excel);
- `/sites` — включить или отключить сайт кнопкой.

## Запуск

```bash
pip install -r requirements.txt
cp .env.example .env   # вписать BOT_TOKEN и ADMIN_IDS
python bot.py
```

Проверка поиска без бота: `python checker.py "термофор ставр"`.

## Как добавить сайт

Добавить блок в `sites.json`:

```json
{
  "name": "Название",
  "enabled": true,
  "search_url": "https://site.ru/search/?q={query}",
  "card": "CSS-селектор карточки товара в результатах поиска",
  "title": "CSS-селектор ссылки с названием внутри карточки",
  "in_stock": ["В наличии"],
  "out_of_stock": ["Нет в наличии", "Под заказ"]
}
```
